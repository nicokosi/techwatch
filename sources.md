# Sources

A starter set: replace it with the feeds you actually read.

One feed per `- <url>` line, under a `## <category>` heading. Check them with
`mise run sources`. Add a source when it keeps showing up elsewhere; drop it when it
never makes the digest. A Bluesky profile is a feed too: `bsky.app/profile/<handle>/rss`;
prefer it when the person's blog has no working feed.
